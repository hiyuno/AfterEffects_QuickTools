# After Effects CEP plugin scaffolding

Antes de correr este plugin, agrega `CSInterface.js` (provisto por Adobe) en
la raíz de esta carpeta — lo referencia `client/index.html`. Se obtiene del
repositorio oficial de Adobe: `Adobe-CEP/CEP-Resources` (carpeta
`CEP_10.x/CSInterface.js` en GitHub). No se incluye aquí porque es un archivo
de terceros mantenido por Adobe, no parte de este scaffolding.

Para desarrollo local sin firmar, habilita `PlayerDebugMode` en las
preferencias de CEP de tu sistema (ver `docs/extendscript-cep-overview.md`).
